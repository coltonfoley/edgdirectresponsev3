# EDG Patio & Shade - Content Optimization Checklist

## How to Use This Checklist

- Use this for every new page and during content audits
- Check off items as completed
- Score each page before publishing (aim for 90%+)
- Review quarterly for existing pages

---

## Universal Page Requirements

### Technical SEO (All Pages)

- [ ] **Title Tag** (50-60 characters)
  - Primary keyword near beginning
  - Brand at end (EDG Patio & Shade / EDG)
  - Unique across site
  - No duplicate titles

- [ ] **Meta Description** (150-160 characters)
  - Includes primary keyword
  - Compelling call-to-action
  - Unique across site
  - Accurately describes content

- [ ] **Canonical URL**
  - Self-referencing canonical set
  - No conflicting canonicals
  - HTTPS protocol
  - www subdomain (consistent)

- [ ] **URL Structure**
  - Lowercase
  - Hyphens between words
  - No special characters
  - Descriptive (no IDs unless necessary)
  - Under 100 characters

- [ ] **Schema Markup**
  - Appropriate schema type selected
  - Required fields populated
  - JSON-LD format
  - Validates in Google's Rich Results Test

- [ ] **Page Speed**
  - Images optimized
  - Lazy loading for below-fold images
  - No render-blocking resources
  - Core Web Vitals passing

- [ ] **Mobile Optimization**
  - Responsive design
  - Touch targets 48px minimum
  - Readable font sizes (16px minimum)
  - No horizontal scrolling

### Content Structure (All Pages)

- [ ] **H1 Tag**
  - One per page only
  - Includes primary keyword
  - Descriptive of page content
  - Compelling to readers

- [ ] **Heading Hierarchy**
  - Logical H1 → H2 → H3 flow
  - No skipping levels
  - Keywords in subheadings where natural
  - Descriptive, scannable headings

- [ ] **Content Length**
  - Minimum 600 words (product pages)
  - Minimum 1,000 words (service areas)
  - Minimum 1,500 words (guides)
  - Comprehensive coverage of topic

- [ ] **Introduction**
  - Hook in first sentence
  - Primary keyword in first 100 words
  - Clear value proposition
  - Sets expectations for content

- [ ] **Conclusion/CTA**
  - Summarizes key points
  - Clear call-to-action
  - Links to next logical step
  - Reinforces value proposition

- [ ] **Readability**
  - Short paragraphs (3-4 sentences max)
  - Bullet points for lists
  - Bold/italic for emphasis
  - Transition words between sections
  - Flesch Reading Ease score 60+

### Internal Linking (All Pages)

- [ ] **Navigation Links**
  - Link to parent/hub page
  - Breadcrumb navigation present
  - Related content links

- [ ] **Contextual Links**
  - 2-3 links to related products/guides
  - Natural anchor text
  - Links spread throughout content
  - No orphaned pages

- [ ] **CTA Links**
  - Contact/quote link above fold
  - Contact/quote link at bottom
  - Relevant product links
  - Phone number clickable

### Media (All Pages)

- [ ] **Images**
  - At least 2-3 images per page
  - Descriptive file names
  - Alt text with keywords (naturally)
  - Compressed for web
  - Relevant to content

- [ ] **Videos** (if applicable)
  - Embedded properly
  - Custom thumbnail
  - Relevant to content
  - Short (under 2 minutes ideal)

## Scoring System

### Page Quality Score

Calculate score: **(Items Checked / Total Items) × 100**

| Score | Rating | Action |
|-------|--------|--------|
| 95-100 | Excellent | Publish |
| 85-94 | Good | Minor tweaks, then publish |
| 75-84 | Acceptable | Address gaps before publishing |
| Below 75 | Needs Work | Major revisions required |

### By Page Type Targets

| Page Type | Minimum Score | Target Score |
|-----------|--------------|--------------|
| Homepage | 95 | 98 |
| Product Pages | 90 | 95 |
| Service Areas | 90 | 95 |
| Guide Pages | 92 | 97 |
| Zoning Guides | 88 | 93 |
| Commercial Pages | 90 | 95 |

## Quarterly Audit Checklist

### Review All Pages

- [ ] Check for broken links
- [ ] Verify all images loading
- [ ] Update outdated content
- [ ] Check for new keyword opportunities
- [ ] Review analytics performance
- [ ] Identify pages needing expansion
- [ ] Update year in titles (if applicable)
- [ ] Refresh CTAs if needed
- [ ] Check competitor content updates
- [ ] Update internal linking

### Content Refresh Priority

**Refresh Immediately:**
- Pricing information (quarterly)
- Zoning/permit requirements (when regulations change)
- Year references (annual)
- Statistics/data (annual)

**Refresh as Needed:**
- Product specifications (when products change)
- Case studies (add new ones)
- Testimonials (add new ones)
- Images (if better available)
