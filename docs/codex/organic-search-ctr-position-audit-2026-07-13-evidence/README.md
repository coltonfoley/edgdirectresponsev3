# Organic Search Audit Evidence — 2026-07-13

This folder contains the read-only evidence used for the dated organic Search
CTR and average-position audit.

## Search Console exports

- `last-3-months/`: Web, April 12–July 11, 2026.
- `last-3-months-vs-previous/`: Web, April 12–July 11, 2026 compared with January 11–April 11, 2026.
- `recent-28-days-vs-previous/`: Web, June 14–July 11, 2026 compared with May 17–June 13, 2026.
- `representative-suspect-query/`: the exact query `automated retractable pergolas hewlett harbor`, Web, April 12–July 11, 2026.

The exports came from the signed-in Google Search Console property
`sc-domain:edgpatioshade.com` in the currently open Comet profile on July 13,
2026. Google Search Console query tables omit anonymized queries and can be
row-limited, so query-row totals must not be treated as property totals. Page
rows can also exceed query totals because more than one EDG URL may appear for
the same query.

## Manual filter observations

`manual-query-page-observations.csv` records focused query-to-page filters read
directly in the same signed-in Search Console session. These filters are used
to diagnose page ownership, host consolidation, and intent overlap; they are
not additive property totals.
